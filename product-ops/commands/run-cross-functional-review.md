---
description: Design and facilitate a cross-functional product review that builds alignment across teams. Use this skill when a product decision or initiative needs structured review and input from multiple functions.
---

Ask the user for: initiative or decision being reviewed, functions that need to be involved. Optionally: current review process and pain points, decision timeline, prior cross-functional conflict points.

Apply the skill at skills/run-cross-functional-review/SKILL.md.

If required inputs are missing, list them and stop. Output: review scope and decision to be made, participant list with roles (decide / advise / inform), pre-read structure and content, session agenda and facilitation guide, decision documentation template, concern and blocker escalation path, action item format with owners.
