---
description: Write a clear design brief that gives designers the problem framing, constraints, and success criteria they need to start design work. Use this skill when handing a problem from product to design for exploration.
---

Ask the user for: problem to be solved, target user or segment, goal or desired outcome. Optionally: research findings or user insights, known constraints (technical, business, time), existing design patterns or system constraints, non-goals.

Apply the skill at skills/write-design-brief/SKILL.md.

If required inputs are missing, list them and stop. Output: problem statement, target user and context, desired outcome, constraints, non-goals, success criteria, supporting materials, open questions for the designer.
