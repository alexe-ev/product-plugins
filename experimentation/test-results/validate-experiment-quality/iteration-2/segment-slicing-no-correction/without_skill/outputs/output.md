# Experiment Quality Validation: Email Personalisation Algorithm

## Summary Assessment
**No, this is not a valid basis for the shipping decision.** There are several critical quality issues with this analysis that must be addressed before making a shipping decision.

## Critical Issues

### 1. Post-hoc Segmentation Inflates False Positive Risk

The segment analysis was conducted **after observing that the overall result was not statistically significant** (p=0.14). This is post-hoc slicing — looking for patterns that weren't pre-specified in the experimental design.

When you run segment analyses after seeing an overall null result, you dramatically increase the risk of false positives because:
- You're implicitly running multiple tests on the same data
- You're prone to "looking for the signal" in subgroups after the main effect disappears
- The data has already been observed, so any pattern you find could be noise rather than true signal

This is a fundamental violation of sound experimental practice.

### 2. Multiple Comparisons Problem Without Correction

You tested 3 segments without applying any multiple-comparison correction:
- Power users (top 20%): p=0.031
- Mid-tier users (middle 60%): p=0.41
- Light users (bottom 20%): p=0.67

**The false positive rate calculation:** With 3 independent hypothesis tests at α=0.05, the probability of observing at least one false positive is:
- P(at least one false positive) = 1 - (0.95)³ ≈ **14.26%**

This is much higher than the intended 5% significance level.

**Applying Bonferroni correction:** With 3 tests, the corrected threshold is α/3 = 0.05/3 ≈ **0.0167**. The power-user result (p=0.031) does **not** survive this correction. It fails to meet the stricter threshold needed to account for multiple testing.

### 3. Business Value Does Not Eliminate Statistical Error

The team's argument that power users are "the most valuable customers" is understandable from a business perspective, but **business importance does not reduce statistical error risk**.

In fact, the opposite is true: because power users generate disproportionate value, a false positive that causes you to deploy an ineffective (or harmful) treatment to this segment would waste resources and potentially damage the customer relationship. The higher the stakes, the higher the statistical rigor should be.

### 4. This Is Hypothesis-Generating, Not Hypothesis-Confirming

The power-user finding (2.5pp increase) is interesting and plausible — personalization may well work better for engaged users who already buy frequently. However, this finding was generated by exploring the data *after seeing the overall null result*.

In experimental science, this distinction is critical:
- **Hypothesis-confirming:** Pre-specified analysis of pre-specified segments. Strong evidence.
- **Hypothesis-generating:** Post-hoc analysis of exploratory segments. Generates ideas for future testing, but does not confirm hypotheses.

This finding falls into the hypothesis-generating category.

## Recommendation

**Do not ship to power users based on this analysis.** Instead:

1. **Document the finding:** Record the post-hoc observation that power users showed a +2.5pp effect in the exploratory segment analysis. This is a valuable hypothesis.

2. **Conduct a fresh pre-registered experiment** specifically designed to test this hypothesis:
   - Pre-register the primary segment of interest (power users, defined by the same 90-day purchase history cutoff)
   - Set the sample size and stopping rule in advance
   - Pre-specify power-user-relevant metrics (not just 7-day purchase rate, but metrics that matter to high-value customers)
   - Include a multiple-comparison correction from the start if testing multiple segments

3. **Only ship if the new experiment confirms the finding:** If the fresh experiment shows a statistically significant effect (at the appropriate corrected threshold) in the power-user segment, then you have valid grounds to ship.

## Quality Classification

This represents a **Fatal** risk to the shipping decision:
- Post-hoc slicing without multiple-comparison correction is a well-documented source of false positives in experimentation
- The p-value does not survive correction
- Using exploratory findings as confirmatory results violates basic experimental standards

The team should treat this as an opportunity to run a better-designed experiment rather than a shortcut to shipping.
