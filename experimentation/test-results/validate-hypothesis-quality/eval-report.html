Итерация 2
Что изменилось в SKILL.md
Три целевых правки, каждая закрывает конкретный паттерн ошибок baseline-модели
1
4-tier verdict system — явные критерии классификации
❌ Проблема (without_skill)

Модель выдаёт числовые шкалы: 6.7/10, D+, MODERATE. Команда не понимает — это go или no-go. Нет единого формата между разными прогонами.

✅ Решение в SKILL.md

Добавлен раздел "4-tier verdict system" с явными условиями входа/выхода для каждого уровня. Теперь вердикт — ровно одна из четырёх строк. Результат: 3/3 vs 0/3 во всех eval cases.

2
Scope discipline — запрет на элементы дизайна эксперимента
❌ Проблема (without_skill)

Даже для слабой гипотезы модель добавляет sample size, power analysis, длительность теста, трафик-сплит. Это создаёт иллюзию готовности там, где её нет.

✅ Решение в SKILL.md

Раздел "Scope discipline — critical": явный запрет включать experiment design elements для гипотез ниже уровня Valid for experiment design. Самый дискриминирующий assertion (0/3 без скилла).

3
Readiness statement — обязательное явное заключение
❌ Проблема (without_skill)

Итоговое заключение размыто или противоречиво: "условно готова", "требует уточнений" без конкретного вывода. Нестабильность: stddev = 0.218 в E2.

✅ Решение в SKILL.md

Требование: отдельная секция с одним конкретным предложением — готова/не готова и почему. Снижение вариативности E2: stddev 0.218 → 0.000 в итерации 2.

Baseline analysis

✓ Что baseline делает хорошо
✓ Находит проблему смешанных изменений в E1 (3/3 runs)
✓ Выделяет расплывчатость «UX-улучшения» и «активации» в E2
✓ Предлагает улучшенную версию гипотезы с конкретными числами
✓ Для по-настоящему сильной гипотезы даёт верный вердикт без скилла
✗ Систематические паттерны ошибок

✗ Нет 4-tier вердикта: использует числовые шкалы — 2/10, D+, MODERATE (0/3 без скилла)
✗ Размытое заключение: нет явного go/no-go в итоговой секции
✗ Нестабильность: stddev = 0.139 — разные ответы на один и тот же запрос
Итоги
Ключевые выводы
📈
Delta выросла с +0.143 до +0.397 — почти трёхкратный рост эффекта скилла. with_skill = 1.000 с нулевым stddev в обеих итерациях — скилл даёт полностью стабильный результат.
🎯
Главный источник ценности скилла — два поведения с MAX разрывом: (1) отсутствие experiment design elements для слабых гипотез и (2) использование 4-tier классификации вместо числовых шкал. Оба: 3/3 vs 0/3 во всех прогонах.
🔄
Замена E3 с ceiling-кейса на пограничный (неправдоподобный эффект-сайз) устранила blind spot в eval-наборе — теперь все три кейса дискриминирующие. Это само по себе важный методологический результат.
⚡
Scope discipline — труднее всего для baseline без инструкции. Без явного запрета в SKILL.md модель консистентно добавляет нерелевантные элементы дизайна (0/3 без скилла во всех eval cases).
