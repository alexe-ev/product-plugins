---
description: Synthesize large volumes of customer feedback into structured themes and actionable product signals. Use this skill when feedback has been collected and needs to be organized into patterns that inform product decisions.
---

Ask the user for: feedback sources and rough volume, synthesis goal (what decisions will this inform?). Optionally: raw feedback data or samples, segment breakdown of feedback sources, prior synthesis for comparison, product area focus.

Apply the skill at skills/synthesize-feedback-themes/SKILL.md.

If required inputs are missing, list them and stop. Output: feedback source inventory, theme set (5-8 themes), each theme with description and frequency and representative quotes and segment breakdown, top themes by volume, high-emotion themes, implicit needs, recommended actions per theme.
