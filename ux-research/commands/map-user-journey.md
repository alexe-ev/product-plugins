description: Create a structured user journey map showing steps, touchpoints, emotions, and pain points across a product or service experience. Use this skill when a team needs a shared view of the end-to-end user experience to identify improvement opportunities.
---

Ask the user for: product or service area to map, user segment or persona, research data (interviews, support logs, analytics). Optionally: existing process documentation, analytics data by journey stage, support ticket themes, prior journey maps.

Apply the skill at skills/map-user-journey/SKILL.md.

If required inputs are missing, list them and stop. Output: journey map with stages/steps/touchpoints/emotions/pain points, evidence quality per stage, top friction moments, opportunity areas by stage, cross-team handoff points, open research questions.
