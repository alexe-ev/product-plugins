---
description: Incorporate architectural constraints and technical debt into product prioritization decisions. Use this skill when a team needs to balance feature work with technical investment.
---

Ask the user for: feature or initiative backlog, technical debt or architecture constraints (as described by engineering), business goals. Optionally: engineering capacity breakdown, current system limitations, migration or upgrade plans.

Apply the skill at skills/prioritize-architecture-aware/SKILL.md.

If required inputs are missing, list them and stop. Output: technical constraint summary in product terms, trade-off assessment, recommended investment ratio and rationale, sequencing recommendation, dependencies between technical and feature work, assumptions from engineering that need validation.
