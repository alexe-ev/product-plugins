description: Design a user onboarding flow that gets new users to the activation moment as quickly as possible. Use this skill when onboarding is too long, confusing, or failing to deliver early value.
---

Ask the user for: product description and target user, activation event (what does it mean for a user to have experienced core value?), current onboarding steps (if any). Optionally: drop-off data by onboarding step, user research on early friction, competitive onboarding benchmarks, time-to-activation data.

Apply the skill at skills/design-onboarding-flow/SKILL.md.

If required inputs are missing, list them and stop. Output: activation event definition, critical path to activation, steps to defer post-activation, onboarding flow structure with rationale, personalization hooks, empty state guidance, follow-up touchpoint plan, success criteria.
