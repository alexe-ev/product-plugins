---
description: Help teams define and structure goals using OKRs, KPIs, and related frameworks. Use this skill when a team needs to set clear, measurable goals aligned with business strategy.
---

Ask the user for: business or product area, strategic priority or direction (even rough). Optionally: company-level OKRs, current metrics baseline, time horizon (quarter, half-year), prior OKR performance.

Apply the skill at skills/set-goals-okrs-kpis/SKILL.md.

If required inputs are missing, list them and stop. Output: objectives (1-3), key results per objective (2-4 each), KPIs for ongoing monitoring, baseline values where known, assumptions behind each KR, risks to goal achievement, confidence level (provisional / context-informed / ready-to-commit).
