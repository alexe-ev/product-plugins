description: Define quality criteria for AI features and set up monitoring, evaluation, and iteration loops. Use this skill when a team needs to ensure their AI feature maintains acceptable quality in production.
---

Ask the user for: AI feature description and expected output, user-facing quality implications (what does "bad" look like to users?). Optionally: model being used, current quality data or error samples, regulatory or compliance requirements, evaluation dataset availability.

Apply the skill at skills/evaluate-ai-quality-monitoring/SKILL.md.

If required inputs are missing, list them and stop. Output: quality dimensions and definitions, quality thresholds, evaluation methodology, monitoring plan, alerting and escalation design, iteration loop from finding to fix, open questions and risks.
