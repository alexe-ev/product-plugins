---
description: Analyze and structure findings from usability testing sessions into prioritized, actionable design recommendations. Use this skill after usability testing to turn observations into improvements.
---

Ask the user for: session notes, recordings, or observation logs, tasks or scenarios used in the study. Optionally: completion rates or task timing data, prior usability findings for comparison, severity rating criteria.

Apply the skill at skills/analyze-usability-findings/SKILL.md.

If required inputs are missing, list them and stop. Output: finding set organized by theme or task area, each finding with description/evidence/severity/affected participants, design recommendations per finding, priority-ordered action list, quick wins, open questions for next round of research.
