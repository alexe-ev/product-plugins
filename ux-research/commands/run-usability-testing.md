---
description: Structure and synthesize usability testing sessions and feedback loops. Use this skill when a team needs to evaluate a design or flow by observing real users attempting to use it.
---

Ask the user for: product flow or feature to be tested, key user tasks to test. Optionally: design prototype or staging environment, target participant criteria, hypotheses about friction points, prior usability test findings.

Apply the skill at skills/run-usability-testing/SKILL.md.

If required inputs are missing, list them and stop. Output: test tasks and success criteria, testing method and participant criteria, test script outline, findings organized by severity, specific friction points with supporting observations, recommended fixes.
