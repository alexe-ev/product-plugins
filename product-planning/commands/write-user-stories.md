---
description: Write well-formed user stories with clear acceptance criteria ready for development. Use this skill when a team needs to break down a feature or initiative into development-ready stories.
---

Ask the user for: feature or initiative description, target user, goal or outcome the feature serves. Optionally: PRD or requirements document, design files or mockups, technical constraints, existing story drafts.

Apply the skill at skills/write-user-stories/SKILL.md.

If required inputs are missing, list them and stop. Output: story set organized by epic or theme, each story with (user type, action, outcome, acceptance criteria), edge cases and error state handling per story, definition of done, stories flagged as blockers, estimated story count and rough scope signal.
