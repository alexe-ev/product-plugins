---
description: Define the primary metric, secondary metrics, guardrails, and success criteria for a product experiment. Use this skill when the user has a hypothesis or planned test but has not yet defined how success should be measured.
---

Ask the user for: hypothesis, business or user goal. Optionally: product metric tree, funnel structure, baseline metrics, known trade-offs, segment context, risk tolerance.

Apply the skill at skills/define-success-metrics/SKILL.md.

If required inputs are missing, list them and stop. Output: primary metric with rationale, secondary metrics, guardrail metrics, minimum meaningful effect, success threshold, neutral zone, failure threshold, interpretation notes, provisional items flagged.
