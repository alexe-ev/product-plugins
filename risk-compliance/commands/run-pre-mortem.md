---
description: Run a pre-mortem analysis to identify ways a product initiative could fail before it launches. Use this skill when a team wants to proactively surface failure modes and plan mitigations before committing to execution.
---

Ask the user for: initiative or plan being evaluated, context (scope, timeline, team, key dependencies). Optionally: prior failure patterns from similar initiatives, stakeholder concerns, known technical or market uncertainties.

Apply the skill at skills/run-pre-mortem/SKILL.md.

If required inputs are missing, list them and stop. Output: pre-mortem framing statement, failure mode list by category with likelihood/severity/in-team-control, top 3-5 failure modes, mitigations for top failure modes, plan adjustments, early warning signals.
