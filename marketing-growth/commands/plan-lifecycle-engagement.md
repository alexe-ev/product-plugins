---
description: Design a lifecycle engagement strategy including onboarding, nurture, and re-engagement flows. Use this skill when a team needs to systematically improve how they engage users across their lifecycle.
---

Ask the user for: product type and user journey, current activation and retention metrics (rough). Optionally: user segments, current lifecycle touchpoints, behavioral triggers available, messaging channels (email, in-app, push).

Apply the skill at skills/plan-lifecycle-engagement/SKILL.md.

If required inputs are missing, list them and stop. Output: lifecycle stage map, touchpoint design per stage (trigger/message goal/channel), priority ranking of lifecycle interventions, success metrics per stage, automation opportunities, data and tooling requirements.
