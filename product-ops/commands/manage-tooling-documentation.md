---
description: Establish or audit tooling stacks and documentation practices for product teams. Use this skill when a team's tools or documentation are creating friction or inefficiency.
---

Ask the user for: current tooling landscape (even rough list), team type and size, key documentation needs. Optionally: pain points with current tools, budget constraints, cross-team tool dependencies.

Apply the skill at skills/manage-tooling-documentation/SKILL.md.

If required inputs are missing, list them and stop. Output: current tooling audit, recommended tooling stack by category, documentation standards, documentation health assessment (what exists, what's missing, what's outdated), recommended actions for immediate improvement, governance (who owns tool administration and documentation upkeep).
