Самый сложный кейс: CUPED significance flip

Без словесных подсказок: только pre-p=0.091, post-p=0.028, «pre-experiment engagement as covariate». Базовая модель без скила написала:

«A large significance flip can indicate either legitimate noise reduction or potential data quality issues. The covariate 'pre-experiment engagement' is severely underspecified — no metric definition, no time window, no confirmation of non-overlap. If the pre-experiment window includes any days during the 21-day test period, the covariate becomes post-treatment measurement that itself responds to the treatment, inducing bias rather than reducing it.»

Модель самостоятельно идентифицировала data leakage risk, правильно назвала механизм (post-treatment measurement) и применила Bonferroni к двум тестам. Скил ничего нового не добавил.

Ключевые выводы

🧠
Implicit числовые ловушки тоже не работают
Гипотеза: если убрать словесные сигналы и дать только числа (таблица enrollment, p-values без комментариев) — baseline споткнётся. Нет. Модель просуммировала колонки таблицы, вычислила χ² для SRM, применила Bonferroni для 3 сегментов, идентифицировала data leakage в CUPED — без подсказок.
📊
SRM, CUPED leakage, Bonferroni — всё знает
Три технически сложных паттерна, которые обычно требуют специальной подготовки: SRM detection из raw enrollment, data leakage через post-treatment covariate, и multiple comparison correction для post-hoc сегментирования. Baseline знает все три. Область слишком хорошо задокументирована в открытом корпусе.
🎯
Реальная ценность скила: структура + restraint
Ценность в двух вещах: (1) стандартизированный риск-словарь (Fatal/Manageable/Unresolved) для downstream handoff; (2) явный запрет на Trust verdict при неполной процедурной информации — baseline иногда пишет «вероятно нормально» вместо полного списка missing evidence.
🏗️

100% vs 100%
0pp разрыв устойчив даже на implicit числовых ловушках. Две итерации, 6 eval-кейсов, от явных словесных паттернов до скрытых числовых аномалий (SRM в таблице, CUPED significance flip, Bonferroni для post-hoc сегментов) — базовая модель проходит все без скила. Это structural skill: его ценность в нормализации риск-словаря и audit checklist для downstream handoff, а не в исправлении ошибок рассуждения. Потенциальный реальный Gap — missing evidence restraint: заставить модель явно перечислить все отсутствующие процедурные свидетельства и отказаться от Trust verdict вместо «вероятно нормально».
