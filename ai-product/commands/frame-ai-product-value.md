---
description: Frame the value of an AI feature in terms of user outcomes and business impact, not model capabilities. Use this skill when a team needs to articulate why an AI feature is worth building and what success looks like.
---

Ask the user for: AI capability or feature idea, target user segment. Optionally: user research on the problem area, comparable AI features in the market, cost or complexity of building, existing baseline (what users do today without AI).

Apply the skill at skills/frame-ai-product-value/SKILL.md.

If required inputs are missing, list them and stop. Output: user problem statement, current user behavior without AI, AI-delivered outcome (user-centric), business value translation, risk identification, success definition, build / don't build recommendation with rationale.
