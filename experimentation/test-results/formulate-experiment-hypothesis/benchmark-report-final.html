Key Findings
Confirmed Skill value is real and robust
Delta increased from +58.1pp to +63.1pp despite replacing an easy assertion with a harder one. with_skill maintains perfect 100% across 18 runs with zero variance. This is not a measurement artifact.
Validated Scope discipline is the strongest differentiator
The new "no experiment design elements" assertion achieves perfect discrimination: 3/3 with_skill pass, 0/3 without_skill pass. Baseline consistently includes sample sizes, p-values, and test durations — the skill reliably stays in its lane.
Observation Rich context eval has highest baseline variance
Rich context without_skill σ = 0.297 (range 0.22–0.78). When the input provides enough context, baseline sometimes performs well. This is expected — the skill adds less value when the problem is already well-defined.
Observation Skill adds most value in low-context scenarios
Light context delta = +72.3pp, Poor context delta = +61.3pp, Rich context delta = +55.7pp. The skill's structured approach and guardrails matter most when the input is vague or poorly defined — exactly where product teams need the most help.
Limitation 1 of 6 Eval 3 assertions is non-discriminating
"Discovery questions or next steps suggested" passes 3/3 in both configs. This is a floor assertion — useful as a sanity check but contributes no delta signal. Consider replacing with a more specific check if further iteration is needed.
Estimate True delta likely ~45–55pp after adjusting for vocabulary compliance
2–3 assertions per eval test SKILL.md-specific vocabulary (e.g., "provisional" label, "If we change X for Y" format) rather than user-observable quality. Removing these would bring the measured delta closer to ~45–55pp — still a substantial and meaningful improvement.
