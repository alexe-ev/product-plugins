Ask the user for: developer product type (API, SDK, platform, data product), target developer segment (skill level, use case, integration context). Optionally: developer feedback or support patterns, time-to-first-call data, competitive DX benchmarks, current documentation state.

Apply the skill at skills/design-developer-experience/SKILL.md.

If required inputs are missing, list them and stop. Output: developer persona(s), developer journey map, hello world path, documentation structure, friction points and proposed solutions, developer support model, DX success metrics.
