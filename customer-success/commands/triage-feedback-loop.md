Apply the skill at skills/triage-feedback-loop/SKILL.md.

If required inputs are missing, list them and stop. Output: feedback source map with volume estimates, tagging taxonomy, triage process design (who, how often, criteria), routing rules by team, escalation process, feedback-to-action loop, tooling requirements.
