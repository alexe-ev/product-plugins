---

Ask the user for: product description and core user actions, existing growth patterns (rough: "mostly referrals" or "mostly paid"). Optionally: referral or virality data, content or SEO performance, network effect signals, user engagement data.

Apply the skill at skills/identify-growth-loop/SKILL.md.

If required inputs are missing, list them and stop. Output: identified growth loops with cycle descriptions, loop type per loop, current strength assessment, weakest link in each active loop, missing loops that should exist, priority order for strengthening, investment required per loop improvement.
